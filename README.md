# Joke Central

A web app I'm building week by week for my DISTRIBUTED SYSTEM module.

## Week 1: Basic frontend (HTML, CSS and JavaScript)
- Worked through the PriceList1 and PriceList2 demos to learn how a page is built from HTML, CSS and JavaScript.
- Built a front-end-only jokes app. A list of 10 jokes in a JavaScript array stands in for data that will come from a back end later.
- Enter several jokes and click **Get Joke**:
  - 1 joke shows the question and answer on separate lines.
  - More than 1 shows the jokes in a table.
  - An invalid number shows a message.
- The page is built dynamically from the array using JavaScript, as in the PriceList2 demo.

**Files:** `jokes.html`, `jokes.css`, `jokes.js`

**To run:** Put the files in one folder and open `jokes.html` in a browser.
